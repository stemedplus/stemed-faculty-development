# STEMEd+ Faculty Development has moved

This list is now part of **STEMEd+ Professional Development**:
**https://stemedplus.github.io/stemed-professional-development/** ([repository](https://github.com/stemedplus/stemed-professional-development)).

The new site combines STEMEd+ Professional Learning (K-12 and informal educators) and STEMEd+ Faculty
Development (college faculty, instructors, graduate students, and postdocs), with a filter for your role.

The old address, https://stemedplus.github.io/stemed-faculty-development/, still works: it sends visitors to the new site, keeping any filters in their link.

To suggest or correct a program, use the
[new repository](https://github.com/stemedplus/stemed-professional-development/issues/new/choose).
The history of this list stays here.
